# 聯機桌遊網站

## 目錄結構

- `index.html`：網站前端，與 `questions.json` 同一目錄
- `questions.json`：兩款遊戲的完整題庫
- `server.js`：Node.js + Express + Socket.io 伺服器
- `package.json`：依賴與啟動指令

## 啟動

```bash
npm install
npm start
```

瀏覽器進入：

```text
http://localhost:3000
```

## 房間規則

- 無需註冊
- 暱稱登入
- 房間 4-6 人
- 房主建立房間，其餘玩家輸入相同房間號加入
- 倒計時全部由服務器產生 `endsAt`，客戶端只負責顯示

## 遊戲1

- 10 秒投票
- 伺服器到點鎖定並計票
- 聊天階段不限時
- 所有人按「下一題」才進下一題
- 可篩選題庫分類

## 遊戲2

- 1 名公開法官
- 1 名知情人，只有他知道正確解釋
- 其餘為騙子，彼此不知身份
- 30 秒準備
- 玩家按服務器指定順序，每人 60 秒發言
- 法官選擇知情人
- 猜中：法官與知情人得分
- 猜錯：騙子得分
